# Lógica de Programação III: Laços de Repetição

Resolução de problemas que exigem iterações, contagens e processamento de múltiplos dados.

## Desafios Resolvidos
* **Contagem Regressiva:** Simulação de "bomba relógio" de 30 a 0 segundos.
* **Validação de Dados:** Uso de loops para impedir entradas inválidas (ex: notas fora de 0 a 10).
* **Processamento de Intervalos:** Cálculos de médias e exibição de números entre faixas específicas.
* **Tabuadas Dinâmicas:** Geração de múltiplas tabuadas com base na entrada do usuário.
* **Interatividade:** Sistema que pergunta se o usuário deseja realizar um novo cálculo antes de encerrar.

## Conceitos Técnicos
* **Laços de Repetição:** Uso de `para`, `enquanto` e `faca...enquanto`.
* **Bibliotecas Externas:** Uso da biblioteca `Util` para o comando `aguarde()`.
* **Acumuladores e Contadores:** Variáveis para somar totais e contar ocorrências dentro de loops.

## Tecnologias
* **Linguagem:** Portugol
* **Ambiente:** Portugol Studio
